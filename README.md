# 한모금 (가칭)

SSU HCI 2026 2학기 10조 프로토타입. 소주와 맥주만 마셔본 사람이 익숙한 음료 취향에서 출발해 새로운 술을 찾고, 근처 바에서 10~30mL로 먼저 맛보는 서비스입니다.

**바로 보기:** https://taegyu831.github.io/hanmogeum/ (휴대폰으로 열면 전체 화면으로 보여요)

## 화면 흐름

| 흐름 | 화면 |
| --- | --- |
| A. 취향 발견 | 시작 → 좋아하는 음료 → 소주·맥주에서 아쉬웠던 점 → 새 술을 만나는 방식 → 취향 타입 결과 |
| B. 탐색 | 세로로 넘기는 피드 → 왼쪽으로 밀면 맛 카드 → 탭하면 뒷면(원료, 제조, 숙성, 정보 깊이 조절) |
| C. 체험과 후기 | 근처 한 잔 지도 → 바 상세 → 맛본 뒤 후기 → 후기가 맛 카드에 반영 |
| 내 기록 | 지금 내 취향, 끌린 술, 내가 남긴 후기 |

## 추천 방식

규칙 기반입니다 (머신러닝 아님). 술마다 팀이 정한 맛 점수 12개(단맛, 신맛, 쓴맛, 탄산, 바디감, 알코올 느낌, 과일, 꽃, 곡물, 나무, 연기, 허브)가 있고,

1. Q1에서 고른 음료로 내 취향 점수를 만들고
2. 술의 맛 점수와 곱해 더한 뒤
3. Q2에서 고른 아쉬운 점으로 감점하고
4. 피드에서 끌려요(+0.3배), 패스(-0.2배), 후기에 따라 취향이 계속 바뀝니다.

자세한 규칙은 `data/source/hanmogeum-data.xlsx`의 "답변 변환표", "점수 계산 규칙" 시트와 `js/reco.js`에 있습니다.

## 데이터 고치는 법

술, 바, 후기는 모두 엑셀 하나에서 나옵니다.

1. `data/source/hanmogeum-data.xlsx`를 고칩니다. 머리글과 ID 칸은 바꾸지 마세요.
2. JSON으로 변환합니다.
   ```
   python3 -m venv .venv && .venv/bin/pip install openpyxl
   .venv/bin/python tools/xlsx_to_json.py
   ```
3. 바뀐 `data/*.json`과 엑셀을 커밋합니다.

술의 사실 정보(도수, 원료, 제조, 숙성)는 아직 출처 확인 전 초안입니다. 바 이름, 가격, 후기는 가상 데이터입니다.

## 내 컴퓨터에서 실행

빌드 과정이 없는 정적 사이트입니다.

```
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다. 사용자가 고른 답과 후기는 브라우저(localStorage)에만 저장됩니다. 처음부터 다시 하려면 내 기록 맨 아래 "처음부터 다시 하기"를 누르세요.
